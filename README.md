# DeMonster

A collection of 10,000 one-of-a-kind horned monsters, generated 100% by code. Every DeMonster is born from its number: horns, eyes, mouth, colors, background, animation and art style are all randomly rolled, so no two are the same.

This repo is only the drawing code, [`demonster.js`](demonster.js). No images are stored. Every monster is drawn from its number by this script, so it works as proof of how the collection is made.

## What it draws

| Trait | How many |
| --- | --- |
| Backgrounds | 51 |
| Horn designs | 96 |
| Eye designs | 100 (with 7 pupil types and optional glow) |
| Mouths | 60 |
| Render styles | 15 |
| Animations | 130, plus a mouth move and an effect per monster |
| Palettes | 10 hand-made + generated ones (effectively endless) |

The same number always gives the same monster. A few animated effects (TV static, glitch slices) flicker randomly, but the traits never change.
